Features

Tiled desktop

Up to four live panes fill the workspace. Snap, minimize, restore from the taskbar. GPU-accelerated via egui / wgpu.

Agent sessions

Ctrl+Shift+A launches Claude Code, Codex, or OpenCode with provider detection and Git worktrees.

In-app review

Unified diff of changed and new files. Annotate lines and inject notes back with bracketed paste.

PTY daemon

macOS bundles ship mi-terminal-daemon. Close the UI; the agents keep working. Source builds keep it opt-in.

Local collab

Trusted live sessions over local TLS with device approval. Not a public room.

Agent memory

Private SQLite. Agent proposals stay pending until a human approves. tc-memory CLI and tc-memory-mcp.

Workspaces

Folder-backed. Quick Open Ctrl+P. Built-in viewer, 213 languages, Catppuccin Mocha.

Persistence

Scrollback survives restarts. Broadcast one command to many live terminals with Ctrl+Shift+Enter.

Install

Source only. Homebrew cask and signed DMG are coming — no tap, no public download. The crate binary is mi-terminal. Version 1.2.0 lives in the tree.

From source

git clone https://github.com/MauroProto/terminal-canvas.git
cd terminal-canvas
cargo run --bin mi-terminal

Release binary

cargo build --release
./target/release/mi-terminal

macOS .app

scripts/bundle.sh
scripts/bundle.sh --dmg

Local unsigned bundles are blocked by Gatekeeper on other machines. Signing needs Apple credentials. This is not a public download.
